Simpan file foto kenangan Abi di folder ini, misalnya:
foto1.jpg
foto2.jpg
foto3.jpg
foto4.jpg
foto5.jpg

Lalu daftarkan nama file dan keterangannya di array `CONFIG.PHOTOS` pada file `script.js`.
Jika folder ini masih kosong atau foto belum dimasukkan, website otomatis menampilkan kartu polaroid ilustrasi vintage yang indah.
